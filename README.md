# ai-job-hunt-privacy

Privacy policy page for the **AI Job Hunt** Android app: [`index.html`](index.html).

This repository also hosts [`investment_pipeline/`](investment_pipeline/README.md), a
four-stage LLM pipeline (Analyst -> Risk Manager -> Executor -> Reporter) that turns
market analysis into risk-checked investment decisions, with tiered model assignment,
exposure controls enforced in code, and a hash-chained audit log across the
signal-to-execution workflow.

And [`gold_trader/`](gold_trader/README.md), an XAUUSD signal pipeline built on the same
four-stage framework, with macro-event blackouts, stop-based position sizing, and a
journal-driven feedback loop that measures each signal's outcome and clamps future
conviction and size accordingly.
