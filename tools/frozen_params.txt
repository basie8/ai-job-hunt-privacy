# FROZEN PARAMETERS - the winners carried forward between stages.
#
# This is the ONE file you edit by hand. Everything in MQL5/Presets/ is
# generated, and hand-edits there are discarded on the next build.
#
# Workflow: after each step, copy the winning values in here, then run
#     python3 tools/make_optimisation_sets.py
# and every DOWNSTREAM file picks them up automatically.
#
#   after the exit comparison   -> the winning exit block
#   after the timeframe run     -> InpTfTrade / InpTfMid / InpTfHigh
#   after Stage 1               -> score threshold, margin, ADX floor
#   after Stage 2               -> stop and target geometry
#   ... and so on
#
# Applied to: Compare_TF_* and every Optimise_Stage* file (and their _Swing
# twins). NOT applied to Compare_Exit_*, which exist to define the exits.
#
# Format: one Inp<Name>=<value> per line. Enum values are integers -
# PERIOD_M5=5, PERIOD_M15=15, PERIOD_M30=30, PERIOD_H1=16385,
# PERIOD_H4=16388, PERIOD_D1=16408.
#
